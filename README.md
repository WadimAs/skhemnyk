# Схемник

Пошук схем, boardview і BIOS для ноутбуків по Telegram-каналах. Працює без власного сервера:
GitHub сам кожні 3 години оновлює базу каналів, а сайт на GitHub Pages шукає по ній прямо в браузері,
на телефоні й на ПК. На Android можна додати на головний екран (меню браузера → «Додати на головний екран»).
Після першого завантаження база працює і без інтернету.

**Сайт:** https://wadimas.github.io/skhemnyk/

## Як влаштовано

- `scripts/crawl.py` гортає публічне веб-превʼю `t.me/s/<канал>`: забирає нові пости, а потім
  поступово догортає стару історію (до 250 сторінок на канал за запуск). Акаунт Telegram не потрібен.
- `.github/workflows/update.yml` запускає це за розкладом, комітить `data/` і публікує сайт.
- `index.html` завантажує `data/*.json` і шукає локально: `LA-K991P` = `LAK991P`, `DAO` = `DA0`.
- Форуми й сайти: під результатами є готові посилання пошуку Google `site:` по кожному сайту,
  а також «свіжий» пошук прямо в кожному каналі.

## Додати канал або сайт

Відредагуй `sources.json` (на GitHub натисни олівець ✏️, працює і з телефона) і збережи.
Після збереження оновлення запуститься автоматично.

## Ручний запуск оновлення

Actions → «Оновлення бази і сайту» → Run workflow.

## Тести

`python tests/test_crawl.py`
